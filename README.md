# Seewo-DesktopAnnotation-Replacement - 希沃批注替换

</div>

替换 `希沃桌面 2.0+` 自带的桌面批注程序为其它屏幕批注程序，目前仅支持在 Windows 10 上运行，且仅支持替换为 [InkCanvasForClass Community Edition](https://github.com/InkCanvasForClass/community/) 1.7.18.7 以上的版本。

## 使用方法

1. 从 [releases](https://github.com/EmerMine/Seewo-DesktopAnnotation-Replacement/releases) 页面下载最新发行版，并解压到一个合适的地方。

2. 运行 `Annotation.exe`，单击 `劫持希沃桌面批注` 按钮。

使用 `.\Annotation.exe -settings` 命令打开设置窗口。
